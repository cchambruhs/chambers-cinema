# Design The Marquee desktop theme

Create a theater-style poster wall with individually lit frames, a clear focused title, and quick access to playback and details. Use Jellyfin poster art and support keyboard and mouse browsing. Register the theme in the shared Themes dropdown.

## Scope

Desktop Jellyfin experience only. This draft records the requested design from the approved Chambers Cinema concept board. Implementation and live Jellyfin testing are pending.
