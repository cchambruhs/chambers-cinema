# Collection HQ as the default desktop view

Make Collection HQ the first view on desktop. Show verified Jellyfin counts, recent additions and collection growth, missing titles from the recovery list, and a next-steps widget. Show unavailable data plainly and keep sample metrics in mockups. Add a **Themes** dropdown alongside the top-bar categories. List Collection HQ, InGen Archive, Neural Map, Kamino, and The Marquee. Indicate the active choice, support keyboard navigation and Escape, and remember an explicit choice on this browser while defaulting to Collection HQ on first visit. This PR owns the shared navigation and theme switcher.

## Scope

Desktop Jellyfin experience only. This draft records the requested design from the approved Chambers Cinema concept board. Implementation and live Jellyfin testing are pending.
