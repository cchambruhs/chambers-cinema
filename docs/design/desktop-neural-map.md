# Design the Neural Map desktop theme

Show a selected title at the center of a navigable graph linked to cast, genres, and collections. Include a details panel and keyboard-accessible navigation. Use metadata from Jellyfin and handle missing connections. Register the theme in the shared Themes dropdown.

## Scope

Desktop Jellyfin experience only. This draft records the requested design from the approved Chambers Cinema concept board. Implementation and live Jellyfin testing are pending.
